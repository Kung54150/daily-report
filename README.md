# daily-report — รายงานยอดประจำวัน

เว็บแอปให้แต่ละหน่วยงานกรอกรายงานประจำวันของตนเอง ผู้จัดการดูรวมทุกหน่วยงานและพิมพ์สรุปเป็น A4 สำหรับห้องประชุม
ทำงานบน Google Apps Script + Google Sheets ใช้ได้ทั้งมือถือและคอมพิวเตอร์

## ความสามารถ
- **เข้าระบบด้วยชื่อหน่วยงาน + รหัสผ่าน** ไม่ต้องมีบัญชี Google (จำการเข้าระบบ 30 วัน)
- **หน้าแรกเป็นของหน่วยงานตนเอง** ดูหน่วยงานอื่นได้ที่แท็บ "ทุกหน่วยงาน" (แก้ไขได้เฉพาะของตนเอง)
- แต่ละหน่วยงานมี 3 แท็บ
  1. **รายงานผู้ป่วย** — แบบฟอร์มตามตัวอย่างของแต่ละแผนก (คงพยาบาลคำนวณอัตโนมัติ, ยอดรวมรายหมวด) · ผู้ป่วยใน: กดเลือกห้องว่าง/ห้องรอทำความสะอาดจากปุ่ม หรือพิมพ์ชื่อห้องเอง และกด "แก้ไขรายการห้อง" เพื่อแก้เลขห้อง/ชื่อ เพิ่ม ลบ หรือสร้างเป็นชุด (เช่น A4 01–25) ได้เอง
  2. **อัตรากำลัง** — เวร Day / Night, เลือกชื่อจาก Drop down หรือพิมพ์ชื่อใหม่ (เข้าทะเบียนอัตโนมัติ), หน้าที่ Inc./POC/Clerk/Cc/ออกหน่วย, ลดอัตรากำลัง RN/PN/NA (ชม.)
  3. **เหตุการณ์ผิดปกติ** — ชื่อ-สกุลผู้ป่วย อายุ HN เวลามารับบริการ แพทย์เจ้าของไข้, V/S (BP mmHg, PR/RR ครั้ง/min, T °C, O2 sat %, O2 Room air/Cannula/Mask/ET tube/HF + ปริมาณ), รายละเอียด — กด **+** เพิ่มได้ไม่จำกัด
- **ทะเบียนเจ้าหน้าที่** หน่วยงานเพิ่ม/แก้ไข/ลบเองได้ · ADMIN อัปโหลดรายชื่อประจำเดือน (Excel/CSV)
- **พิมพ์ A4 (ADMIN)**
  - รายงานทั้งหมด: หน้าแยกหน่วยงาน → หน้าภาพรวม/สถิติ → เหตุการณ์ผิดปกติรวมทุกหน่วยงาน
  - เฉพาะหน่วยงาน: รายงานละเอียดของหน่วยงานเดียว

## หน่วยงาน
| กลุ่ม | หน่วยงาน |
|---|---|
| ผู้ป่วยนอก | OPD1, OPD3, ER, HPC, OBG-IVF, PC, EENT, Dent |
| ผู้ป่วยใน | ตึก A: A4, A5, A6 · ตึก B: B3, B4, B5 · ตึก C: C3, C4, C5 (แยกเป็นหัวข้อตึกในรายการหน่วยงาน หน้าเข้าสู่ระบบ และหน้าพิมพ์ พร้อมยอดรวมรายตึก) |
| Special Unit | ICU, LR-NB, ไตเทียม, OR |

> แบบฟอร์มของ ER, HPC, EENT, Dent, C3–C5 และ Special Unit ยังเป็นแบบชั่วคราว (มีป้ายแจ้งในหน้าแบบฟอร์ม)

## ชีตข้อมูล (สร้างอัตโนมัติ)
| ชีต | เนื้อหา |
|---|---|
| `ผู้ใช้` | หน่วยงาน + รหัสผ่าน — **ADMIN แก้รหัสผ่านที่นี่** |
| `รายงาน` | รายงานฉบับเต็มของแต่ละหน่วยงาน/วัน |
| `สถิติ` | ยอดมาตรฐานแบบแถวยาว (วันที่, กลุ่ม, หน่วยงาน, หมวด, รายการ, จำนวน, ตึก) สำหรับ Pivot / Looker Studio — คอลัมน์ `ตึก` เป็น A/B/C สำหรับผู้ป่วยใน |
| `เหตุการณ์ผิดปกติ` | เหตุการณ์ละ 1 แถว พร้อมข้อมูลผู้ป่วยและ V/S |
| `ทะเบียนเจ้าหน้าที่` | รายชื่อ, ตำแหน่ง, ที่มา (upload = จากไฟล์ / manual = เพิ่มเอง) |
| `ห้อง` | ห้องพักของแต่ละหน่วยงาน: หน่วยงาน, เลขห้อง, ชื่อ/ประเภท (ไม่บังคับ) — เริ่มต้นของผู้ป่วยในทุกตึกคือ `<หน่วยงาน>01`–`25` เช่น A401–A425 **แก้ได้ทั้งในเว็บและในชีต** ถ้าใส่ชื่อ (เช่น VIP, ห้องคอก) รายงานจะใช้ชื่อแทนเลขห้อง |
| `ชื่อแผนกในไฟล์` | การผูกชื่อแผนกที่ไฟล์รายชื่อใช้ (เช่น "ศัลยกรรมชาย") กับหน่วยงานในระบบ (เช่น A4) — ผูกตอนตรวจไฟล์อัปโหลด หรือเพิ่ม/ลบในหน้า "รายชื่อเจ้าหน้าที่" ของ ADMIN |

ยอดมาตรฐานที่ใช้วิเคราะห์ข้ามหน่วยงาน
- ผู้ป่วยนอก: ผู้ป่วยทั้งหมด, Admit, Refer
- ผู้ป่วยใน: ยกมา, รับใหม่, รับย้าย, ย้ายไป, Refer, Dead, จำหน่าย, คงพยาบาล + ประเภทผู้ป่วย (จัดกลุ่มชื่อที่ต่างกันให้นับรวมกันได้ เช่น นรีเวช/สูติ → สูติ-นรีเวช)

## อัปโหลดรายชื่อเจ้าหน้าที่ (ADMIN → แท็บ "รายชื่อเจ้าหน้าที่ (อัปโหลด)")
ไฟล์ Excel (.xlsx) หรือ CSV มีคอลัมน์ `หน่วยงาน` (ชื่อตรงกับระบบ เช่น A4, OPD1, ICU — ยอมรับ `ตึก A ชั้น 4` และตัวพิมพ์เล็ก), `ชื่อ-สกุล`, `ตำแหน่ง` (RN/PN/NA หรือ พยาบาลวิชาชีพ/ผู้ช่วยพยาบาล/ผู้ช่วยเหลือผู้ป่วย/นักศึกษา) ลำดับคอลัมน์ใดก็ได้ถ้ามีหัวตาราง ในหน้าอัปโหลดมีปุ่มดาวน์โหลดไฟล์ตัวอย่าง ชื่อจะเข้าทะเบียนของแต่ละหน่วยงานตามคอลัมน์หน่วยงาน
- รายชื่อ "จากไฟล์" เดิมของหน่วยงานที่อยู่ในไฟล์จะถูกแทนที่ทั้งหมด
- ชื่อที่หน่วยงานพิมพ์เพิ่มเองแล้วซ้ำกับไฟล์ → ยึดข้อมูลจากไฟล์

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | ฝั่งเซิร์ฟเวอร์: เข้าระบบ, บันทึกรายงาน, ทะเบียนเจ้าหน้าที่, สถิติ |
| `Schema.gs` | **แบบฟอร์มของแต่ละหน่วยงาน**, ยอดมาตรฐาน, ประเภทผู้ป่วย, ตำแหน่ง, ประเภทเหตุการณ์ |
| `Index.html` | หน้าเว็บทั้งหมด |
| `appsscript.json` | ตั้งค่าโปรเจกต์ (เขตเวลา Asia/Bangkok, เว็บแอปเปิดได้โดยไม่ต้องล็อกอิน Google) |

## วิธีติดตั้ง
1. สร้าง Google Sheets ใหม่ → **ส่วนขยาย → Apps Script**
2. สร้างไฟล์ให้ครบ: `Code.gs`, `Schema.gs` (สคริปต์) และ `Index` (HTML) แล้ววางโค้ดจาก repo
3. ⚙️ การตั้งค่าโปรเจกต์ → เขตเวลา **(GMT+07:00) Bangkok**
4. (ไม่บังคับ) เปิดไฟล์ `Code.gs` → เลือกฟังก์ชัน **`setup`** แล้วกด **เรียกใช้** — ถ้าข้ามขั้นนี้ ระบบจะสร้างชีตและรหัสผ่านให้เองเมื่อเปิดหน้าเว็บครั้งแรก
5. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน** (ไม่ต้องมีบัญชี Google)
6. เปิด URL `/exec` หนึ่งครั้ง (ระบบสร้างชีต `ผู้ใช้` ให้) แล้วแจก URL กับรหัสผ่านจากชีตนั้นให้แต่ละหน่วยงาน

แก้โค้ดแล้วต้อง Deploy เวอร์ชันใหม่: จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชันใหม่ (URL เดิม)

## ปรับแบบฟอร์ม
แก้ `FORMS` ใน `Schema.gs` — โครงสร้างอธิบายไว้ที่หัวไฟล์ (ช่องตัวเลข/ข้อความ/เวลา, ตาราง, ยอดรวม, ช่องคำนวณ, `std` ยอดมาตรฐาน)
