# daily-report — รายงานยอดประจำวัน

เว็บแอปให้แต่ละแผนกรายงานยอดประจำวัน บันทึกลง Google Sheets ผ่าน Google Apps Script

## ความสามารถ
- **กรอกยอด** — แต่ละแผนกมีรายการไม่เหมือนกัน (ยอดผู้ป่วย / หัตถการ) ส่งซ้ำวันเดียวกันจะแทนที่ของเดิม
- **เหตุการณ์ผิดปกติ** — ประเภทเหตุการณ์, ระดับความรุนแรง A–I, รายละเอียด, การแก้ไขเบื้องต้น
- **สรุปรายวัน** — ดูยอดทุกแผนก แผนกไหนยังไม่รายงาน และเหตุการณ์ผิดปกติของวันนั้น

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | ฝั่งเซิร์ฟเวอร์ + **ตั้งค่าแผนกและรายการ** (`DEPARTMENTS`) |
| `Index.html` | หน้าเว็บ (รองรับมือถือ) |
| `appsscript.json` | ตั้งค่าโปรเจกต์ (เขตเวลา Asia/Bangkok) |

## วิธีติดตั้ง
1. สร้าง Google Sheets ใหม่ → เมนู **ส่วนขยาย → Apps Script**
2. วางโค้ด `Code.gs` และสร้างไฟล์ HTML ชื่อ `Index` แล้ววางโค้ด `Index.html`
3. **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
4. นำ URL ที่ได้ไปแชร์ให้แต่ละแผนก

ชีต `ยอดประจำวัน` และ `เหตุการณ์ผิดปกติ` จะถูกสร้างให้อัตโนมัติเมื่อมีการบันทึกครั้งแรก

## ปรับรายการของแต่ละแผนก
แก้ที่ตัวแปร `DEPARTMENTS` ใน `Code.gs` เช่น

```js
LAB: {
  name: 'ห้องปฏิบัติการ',
  items: [
    { key: 'lab_cbc', label: 'CBC', group: 'หัตถการ', unit: 'ราย' }
  ]
}
```

`key` ต้องไม่ซ้ำกันภายในแผนก แล้ว Deploy เวอร์ชันใหม่
