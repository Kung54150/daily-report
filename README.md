# daily-report — รายงานยอดประจำวัน

เว็บแอปให้แต่ละหน่วยงานกรอกยอดประจำวันของตนเอง ข้อมูลรวมไปที่ผู้จัดการ และพิมพ์สรุปเป็นกระดาษ A4 สำหรับใช้ในห้องประชุม
ทำงานบน Google Apps Script + Google Sheets

## หน่วยงาน
| กลุ่ม | หน่วยงาน |
|---|---|
| ผู้ป่วยนอก | OPD1, OPD3, ER, HPC, OBG-IVF, PC, EENT, Dent |
| ผู้ป่วยใน | A4, A5, A6, B3, B4, B5, C3, C4, C5 |
| Special Unit | ICU, LR-NB, ไตเทียม, OR |

> รายการยอดของแต่ละกลุ่มตอนนี้เป็น **ตัวอย่าง** — จะปรับตามรูปแบบรายงานจริง

## การใช้งาน
| ผู้ใช้ | ลิงก์ | ทำอะไรได้ |
|---|---|---|
| หน่วยงาน | `<URL เว็บแอป>?unit=A4` | กรอกยอด + รายงานปัญหา (ล็อกหน่วยงานไว้ให้) |
| ผู้จัดการ | `<URL เว็บแอป>?view=manager` | ดูสรุปทุกหน่วยงาน, ดูว่าใครยังไม่รายงาน, **พิมพ์ A4** |

- ส่งยอดซ้ำในวันเดียวกัน = แก้ไข (แทนที่ของเดิม) เปิดหน้ากรอกจะแสดงค่าเดิมให้
- หน้าสรุปมีลิงก์ของทุกหน่วยงานให้คัดลอกไปแจกได้
- ปุ่ม **พิมพ์ A4** → เลือกเครื่องพิมพ์ หรือ "บันทึกเป็น PDF"

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `Code.gs` | ฝั่งเซิร์ฟเวอร์ + **ตั้งค่าหน่วยงานและรายการ** (`GROUPS`, `*_ITEMS`) |
| `Index.html` | หน้าเว็บ (กรอกยอด / รายงานปัญหา / สรุป-พิมพ์) |
| `appsscript.json` | ตั้งค่าโปรเจกต์ (เขตเวลา Asia/Bangkok) |

## วิธีติดตั้ง
1. สร้าง Google Sheets ใหม่ → เมนู **ส่วนขยาย → Apps Script**
2. วางโค้ด `Code.gs` และสร้างไฟล์ HTML ชื่อ `Index` แล้ววางโค้ด `Index.html`
3. **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
4. เปิด `<URL>?view=manager` แล้วแจกลิงก์ของแต่ละหน่วยงาน

ชีต `ยอดประจำวัน` และ `ปัญหาประจำวัน` จะถูกสร้างอัตโนมัติเมื่อบันทึกครั้งแรก

## ปรับรายการยอด
แก้ใน `Code.gs`:
- `OPD_ITEMS`, `IPD_ITEMS` … = รายการของแต่ละกลุ่ม
- `overrides` ใน `GROUPS` = หน่วยงานที่รายการต่างจากกลุ่ม (เช่น OR, ไตเทียม, LR-NB)

แก้แล้วต้อง Deploy เวอร์ชันใหม่ (จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่)
