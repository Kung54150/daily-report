# daily-report — รายงานยอดประจำวัน

เว็บแอปให้แต่ละหน่วยงานกรอกรายงานประจำวันของตนเอง ผู้จัดการดูรวมทุกหน่วยงานและพิมพ์สรุปเป็น A4 สำหรับห้องประชุม
ทำงานบน Google Apps Script + Google Sheets ใช้ได้ทั้งมือถือและคอมพิวเตอร์

## ความสามารถ
- **อัตรากำลังผู้ป่วยนอก + แพทย์ออกตรวจ** — Zone OPD ระบุเวลาทำงานของเจ้าหน้าที่แต่ละคนเอง (เริ่ม–เลิก 24 ชม. พิมพ์ 0800 คนถัดไปใช้เวลาเดียวกับคนก่อนหน้าให้ก่อน แก้ได้) เลือกชื่อจาก Drop down เหมือนเดิม · แพทย์แยกลงข้อมูลคนละแท็บกับเจ้าหน้าที่ (แท็บย่อย "แพทย์") ดึงแพทย์ของวันนั้นจากตารางเวรแพทย์ตามสาขาของแผนก แผนกแก้ชื่อ/เวลา เพิ่ม ลบ หรือเลือก "งด / ไม่มา" ได้ตลอดเวลา (ปุ่ม "ดึงจากตารางเวร" เติมแพทย์ที่ยังไม่มี) แพทย์และเวลาแสดงในรายงานอัตรากำลัง สรุป และหน้าพิมพ์
- **อัปโหลดตารางเวรแพทย์ประจำเดือน (ADMIN)** — แท็บ "รายชื่อเจ้าหน้าที่" → การ์ด "ตารางเวรแพทย์ประจำเดือน": อัปโหลดไฟล์ปฏิทิน Excel (ชีตละสาขา) ระบบอ่านเดือน แพทย์ และเวลาออกตรวจรายวัน แล้วให้เลือกว่าแต่ละสาขา (ชื่อชีต) ใช้กับหน่วยงานผู้ป่วยนอกใด (เลือกได้หลายหน่วยงาน ระบบเดาให้ก่อน จำไว้ใช้เดือนถัดไป) ข้อความในตารางที่ระบุหน่วยงาน เช่น (HPC) (OPD+ER) ใช้จับคู่ด้วย · อัปโหลดเดือนเดิมซ้ำจะแทนที่ทั้งเดือน เก็บในชีต `ตารางเวรแพทย์` และ `ผูกตารางแพทย์`
- **ดึงเคสจาก LINE (OPD1)** — บอท LINE (repo ChatBot) แยกชื่อผู้ป่วย เวลา V/S และเหตุการณ์จากข้อความในกลุ่ม OPD1 เก็บเป็นร่างในชีต `เคสจาก LINE` · ในฟอร์มรายงานเคสกด "ดึงเคสจาก LINE" ระบบกรอกช่องให้ (และชื่อผู้รายงานถ้ายังว่าง) ตรวจแล้วกดบันทึก เคสที่บันทึกแล้วจะเป็น "นำเข้าแล้ว" ไม่ถูกดึงซ้ำ · เพิ่มหน่วยงานอื่นได้ที่ `LINE_CASE_UNITS` ใน `Code.gs`
- **ผู้ใช้ 3 แบบ** — หน่วยงาน (กรอก/พิมพ์รายงานของตนเอง) · `MANAGER` ผู้จัดการ (ดูสรุป ติดตามรายแผนก พิมพ์ A4 ดูอย่างเดียว) · `ADMIN` ผู้ดูแลระบบ (ทำได้เหมือนผู้จัดการ + อัปโหลด/ผูกรายชื่อเจ้าหน้าที่ + แก้ห้องทุกหน่วยงาน) รหัสผ่านอยู่ที่ชีต `ผู้ใช้` — ระบบเดิมที่ยังไม่มีแถว `MANAGER` จะเพิ่มให้เองเมื่อเปิดหน้าเว็บ แล้วดูรหัสผ่านที่ชีต
- **พิมพ์รายงานของหน่วยงานเอง** — แท็บ "พิมพ์รายงาน": รายวัน (ตามวันที่เลือก ทุกเวร) หรือรายเดือน (ยอดรายวัน/เวร รวม เฉลี่ย รายการรวมทั้งเดือน และเหตุการณ์ผิดปกติ) ผู้จัดการ/Admin พิมพ์รายเดือนของแต่ละหน่วยงานได้จากแท็บพิมพ์ A4
- **จับคู่ตำแหน่งงานโดยแอดมิน** — ตำแหน่งในไฟล์ที่ระบบไม่รู้จัก (เป็น "อื่นๆ") แอดมินเลือกบทบาท RN/PN/NA/นศ./อื่นๆ ได้ที่การ์ด "จับคู่ตำแหน่งงานกับบทบาท" ในแท็บรายชื่อเจ้าหน้าที่ ผลใช้กับรายชื่อเดิมและการอัปโหลดครั้งต่อไป (เก็บในชีต `การจับคู่ตำแหน่ง` และคอลัมน์ `ตำแหน่งในไฟล์` ของทะเบียน) · แผนกใหม่: ผิวหนัง, แผนจีน, CCC (ฟอร์มตัวอย่างรอปรับ)
- **ธีมรูปภาพ + รูปพื้นหลังของฉัน** — ในปุ่ม "ตั้งค่า": ธีมรูปภาพสำเร็จรูป 12 ธีม (รูปย่อเก็บใน `ThemeImages.gs` โหลดเฉพาะรูปที่เลือกผ่าน `getThemePhoto`; เพิ่มธีมใหม่โดยเพิ่มรูปใน `ThemeImages.gs` และแถวใน `PHOTO_THEMES` ของ `Index.html`) เมื่อเลือกจะปรับสีหลัก/โหมดให้เข้ากับรูป · เลือกรูปจากเครื่องตัวเองเป็นพื้นหลังได้ (เก็บในเบราว์เซอร์ ไม่อัปโหลด) ปรับความเข้มชั้นทับรูป ขนาด (ซูม) และตำแหน่งรูปเองได้ด้วยตัวเลื่อน หมุนรูปเป็นองศาที่ต้องการ (-180° ถึง 180°) และเลือกสีพื้นรอบรูปเมื่อซูมออก (ตามสีขอบรูป / สีธีม / เลือกเอง) · สีพื้นล้วนเหลือ 6 สี
- **ตั้งค่าส่วนตัว** — ปุ่ม "ตั้งค่า" (หน้าเข้าสู่ระบบมีปุ่ม "ธีม"): เลือกธีมสว่าง/มืด/อัตโนมัติตามเครื่อง และสีหลัก 11 สี: โทนพาสเทล 6 สี (มิ้นต์ ฟ้า ม่วง ชมพู พีช และ รพ.เอกชัย — สีของ รพ.เอกชัยแก้ที่ `[data-accent="ekachai"]` ใน `Index.html`) และโทนเข้ม/สุภาพ 5 สี (กรมท่า เขียวหม่น เลือดหมู เขียวเข้ม เทาเข้ม) จำไว้ในเบราว์เซอร์ของแต่ละคน · เปลี่ยนรหัสผ่านของตนเองได้ทุกบทบาท (ต้องกรอกรหัสเดิม อย่างน้อย 4 ตัว ไม่มีช่องว่าง) · ลืมรหัสผ่านให้แจ้ง Admin: Admin กดรีเซ็ตรหัสผ่านให้ผู้ใช้ได้ที่ปุ่มตั้งค่า ระบบสุ่มรหัส 6 หลักใหม่ให้และออกจากระบบเครื่องเดิมของผู้ใช้นั้น (รหัสของ ADMIN เองแก้ในชีต `ผู้ใช้`)
- **แท็บเหตุการณ์ผิดปกติ (ผู้จัดการ/Admin)** — ต่อจากติดตามรายแผนก รวมเหตุการณ์ผิดปกติของวันที่เลือก กรองตามกลุ่มได้ ดูจากมือถือได้โดยไม่ต้องพิมพ์ A4 (ย้ายออกจากหน้าสรุป) · แยกหน่วยงาน LR กับ NB (เดิม LR-NB) รายชื่อที่เคยผูกกับ LR-NB กลับเป็น "ยังไม่ผูกแผนก" ให้แอดมินผูกใหม่ · หน้ารายงานของแผนกแสดงประเภทผู้ป่วยเป็นตาราง ประเภท / จำนวนรวม / ลูกบอลสี
- **ลูกบอลสีผู้ป่วยคงพยาบาล (IPD)** — เมื่อกรอกจำนวนผู้ป่วยแต่ละประเภท (เช่น อายุรกรรม 4) ต้องระบุว่าลูกบอลสีเขียว/เหลือง/ส้ม/แดง กี่ราย (รวมต้องเท่ากับจำนวน) หน้าสรุปแสดงต่อท้ายแต่ละประเภทและบรรทัดสรุปทั้งเวร หน้าภาพรวมมีตารางลูกบอลสีรายตึก · หน้าสรุปแยกแท็บ ผู้ป่วยนอก/ผู้ป่วยใน/Special Unit · หน้าพิมพ์ A4 บนจอแสดงเฉพาะภาพรวม ส่วนเวลาพิมพ์จริงจะมีหน้ารายงานแยกหน่วยงานนำหน้าด้วย
- **ฟอร์มแบบเลือกรายการ + เพิ่ม (HPC)** — เลือกรายการจาก Drop down แล้วกด "+ เพิ่ม" รายการที่ต้องระบุชื่อบริษัทต้องกรอกชื่อก่อนจึงจะเพิ่มได้ ยอดรวมคำนวณเอง แก้รายการได้ที่ `HPC_ITEMS` ใน `Schema.gs`
- **เข้าระบบด้วยชื่อหน่วยงาน + รหัสผ่าน** ไม่ต้องมีบัญชี Google (จำการเข้าระบบ 30 วัน)
- **หน้าแรกเป็นของหน่วยงานตนเอง** ดูหน่วยงานอื่นได้ที่แท็บ "ทุกหน่วยงาน" (แก้ไขได้เฉพาะของตนเอง)
- **รายงานแยกตามเวร Day / Night** — ต้องเลือกเวรทุกครั้งที่กรอก แต่ละวันแต่ละหน่วยงานมีได้ 2 ฉบับ ผู้ป่วยนอกทุกแผนกยกเว้น ER มีเฉพาะเวร Day (ตั้งใน `unitShifts_` ของ `Schema.gs`) แท็บ "สรุป" เริ่มจากผู้ป่วยนอก → ผู้ป่วยใน → Special Unit รายหน่วยงาน (แผนกที่มี 2 เวรแสดงทั้ง Day และ Night ในกล่องเดียวกัน) มีปุ่ม "พิมพ์เอกสาร" ไปหน้าพิมพ์ A4 ซึ่งแสดงทั้งสองเวรในเอกสารเดียวและไม่รวมยอดข้ามเวร แท็บ "ติดตามรายแผนก" แสดงการ์ดแต่ละหน่วยงานว่าส่งครบ / ส่งไม่ครบ / ยังไม่ส่ง
- แต่ละหน่วยงานมี 3 แท็บ
  1. **รายงานผู้ป่วย** — แบบฟอร์มตามตัวอย่างของแต่ละแผนก (คงพยาบาลคำนวณอัตโนมัติ, ยอดรวมรายหมวด) · ผู้ป่วยใน: กดเลือกห้องว่าง/ห้องรอทำความสะอาดจากปุ่ม หรือพิมพ์ชื่อห้องเอง และกด "แก้ไขรายการห้อง" เพื่อแก้เลขห้อง/ชื่อ เพิ่ม ลบ หรือสร้างเป็นชุด (เช่น A4 01–25) ได้เอง
  2. **อัตรากำลัง** — เลือกชื่อจาก Drop down หรือพิมพ์ชื่อใหม่ (เข้าทะเบียนอัตโนมัติ), หน้าที่ Inc./POC/Clerk/Cc/ออกหน่วย, ลดอัตรากำลัง RN/PN/NA (ชม.)
  3. **เหตุการณ์ผิดปกติ** — ชื่อ-สกุลผู้ป่วย อายุ HN เวลามารับบริการ (พิมพ์ 24 ชม. เช่น 2030) แพทย์เจ้าของไข้, V/S (BP mmHg, PR/RR ครั้ง/min, T °C, O2 sat %, O2 Room air/Cannula/Mask/ET tube/HF + ปริมาณ), รายละเอียด, **ไฟล์แนบ JPG/PNG/PDF** (สูงสุด 5 ไฟล์ต่อเหตุการณ์) — กด **+** เพิ่มได้ไม่จำกัด
- **ทะเบียนเจ้าหน้าที่** หน่วยงานเพิ่ม/แก้ไข/ลบเองได้ · ADMIN อัปโหลดรายชื่อประจำเดือน (Excel/CSV)
- **สรุป (ADMIN)** — หน้าจอสำหรับอ่านบนมือถือ เรียงเป็นกล่องคอลัมน์เดียวไม่ต้องเลื่อนซ้ายขวา: ตัวเลขสรุป → ผู้ป่วยนอก (กล่องรวม + กล่องรายแผนก) → ผู้ป่วยในตึก A/B/C → Special Unit → เหตุการณ์ผิดปกติรวมทุกหน่วยงาน (แยกจากหน้าพิมพ์)
- **พิมพ์ A4 (ADMIN)** — แท็บแยกสำหรับดูตัวอย่างและพิมพ์ — ภาพรวมมีคอลัมน์ RN / PN / NA ของแต่ละหน่วยงานและยอดรวมรายตึก, ไฟล์แนบของเหตุการณ์ผิดปกติ (รูป และ PDF หน้าแรกๆ) พิมพ์รวมอยู่ในรายงาน
  - รายงานทั้งหมด: หน้าแยกหน่วยงาน → หน้าภาพรวม/สถิติ → เหตุการณ์ผิดปกติรวมทุกหน่วยงาน
  - เฉพาะหน่วยงาน: รายงานละเอียดของหน่วยงานเดียว

## หน่วยงาน
| กลุ่ม | หน่วยงาน |
|---|---|
| ผู้ป่วยนอก | OPD1, OPD3, ER, HPC, OBG-IVF, PC, EENT, Dent |
| ผู้ป่วยใน | ตึก A: A4, A5, A6 · ตึก B: B3, B4, B5 · ตึก C: C3, C4, C5 (แยกเป็นหัวข้อตึกในรายการหน่วยงาน หน้าเข้าสู่ระบบ และหน้าพิมพ์ พร้อมยอดรวมรายตึก) |
| Special Unit | ICU, LR-NB, ไตเทียม, OR |

> แบบฟอร์มของ HPC, EENT, Dent, C3–C5 และ Special Unit ยังเป็นแบบชั่วคราว (ER ทำตามตัวอย่างจริงแล้ว: ยอดรวมคำนวณจาก OPD + Admit, Triage, รายการอื่นๆ, ผู้สูงอายุ, Trauma HI, เคสหลัง 22.00 น.) (มีป้ายแจ้งในหน้าแบบฟอร์ม)

## ชีตข้อมูล (สร้างอัตโนมัติ)
| ชีต | เนื้อหา |
|---|---|
| `ผู้ใช้` | หน่วยงาน + รหัสผ่าน — **ADMIN แก้รหัสผ่านที่นี่** |
| `รายงาน` | รายงานฉบับเต็มของแต่ละหน่วยงาน/วัน/เวร (คอลัมน์ `เวร`) |
| `สถิติ` | ยอดมาตรฐานแบบแถวยาว (วันที่, กลุ่ม, หน่วยงาน, หมวด, รายการ, จำนวน, ตึก) สำหรับ Pivot / Looker Studio — คอลัมน์ `ตึก` เป็น A/B/C สำหรับผู้ป่วยใน และคอลัมน์ `เวร` เป็น Day/Night (ข้อมูลเก่าที่ไม่มีเวรถือเป็น Day) |
| `เหตุการณ์ผิดปกติ` | เหตุการณ์ละ 1 แถว พร้อมข้อมูลผู้ป่วย V/S และชื่อไฟล์แนบ |
| `ทะเบียนเจ้าหน้าที่` | รายชื่อ, หน่วยงาน (ว่าง = ยังไม่ผูกแผนก), ตำแหน่ง, ที่มา (upload = จากไฟล์ / manual = เพิ่มเอง), แผนกในไฟล์ |
| `ห้อง` | ห้องพักของแต่ละหน่วยงาน: หน่วยงาน, เลขห้อง, ชื่อ/ประเภท (ไม่บังคับ) — เริ่มต้นของผู้ป่วยในทุกตึกคือ `<หน่วยงาน>01`–`25` เช่น A401–A425 **แก้ได้ทั้งในเว็บและในชีต** ถ้าใส่ชื่อ (เช่น VIP, ห้องคอก) รายงานจะใช้ชื่อแทนเลขห้อง |
| `ชื่อแผนกในไฟล์` | การผูกชื่อแผนกที่ไฟล์รายชื่อใช้ (เช่น "ศูนย์อายุรกรรม") กับหน่วยงานในระบบ (เช่น OPD1) — ผูกภายหลังจากอัปโหลดในหน้า "รายชื่อเจ้าหน้าที่" ของ ADMIN |

ยอดมาตรฐานที่ใช้วิเคราะห์ข้ามหน่วยงาน
- ผู้ป่วยนอก: ผู้ป่วยทั้งหมด, Admit, Refer
- ผู้ป่วยใน: ยกมา, รับใหม่, รับย้าย, ย้ายไป, Refer, Dead, จำหน่าย, คงพยาบาล + ประเภทผู้ป่วย (จัดกลุ่มชื่อที่ต่างกันให้นับรวมกันได้ เช่น นรีเวช/สูติ → สูติ-นรีเวช)

## อัปโหลดรายชื่อเจ้าหน้าที่ (ADMIN → แท็บ "รายชื่อเจ้าหน้าที่ (อัปโหลด)")
1. **อัปโหลดไฟล์** Excel (.xlsx) หรือ CSV ที่มีคอลัมน์ ชื่อ-สกุล, ตำแหน่ง และแผนก (หัวตารางอยู่แถวไหนก็ได้ ใช้ชีตแรกที่พบ) ระบบนำเข้า **ทุกคน** พร้อมเก็บชื่อแผนกตามไฟล์ไว้ในช่อง "แผนกในไฟล์" อ่านเฉพาะ 3 คอลัมน์นี้ เลขบัตรประชาชนและวันเกิดไม่ถูกส่งหรือเก็บ
2. **ผูกชื่อแผนก** ในการ์ด "ผูกชื่อแผนกในไฟล์กับหน่วยงานในระบบ" เลือกหน่วยงานที่ตรงกับแต่ละแผนกในไฟล์ (ระบบแนะนำให้บางแผนก เช่น ศูนย์อายุรกรรม → OPD1) แล้วกด "บันทึกการผูก" รายชื่อทั้งแผนกจะเข้าหน่วยงานนั้น ระบบจำการผูกไว้ อัปโหลดครั้งต่อไปจัดเข้าให้เอง คนที่ยังไม่ผูกดูได้ที่ตัวเลือก "ยังไม่ผูกแผนก"
3. ADMIN ย้ายรายบุคคลไปหน่วยงานอื่นได้ที่ปุ่มแก้ไขในทะเบียน

- ชื่อแผนกที่ตรงกับชื่อหน่วยงานในระบบอยู่แล้ว (เช่น `ผู้ป่วยใน A4`, `ตึก A ชั้น 4`, `opd1`) จัดเข้าให้ทันที
- รายชื่อ "จากไฟล์" เดิมของแผนกที่อยู่ในไฟล์ใหม่จะถูกแทนที่ทั้งหมด ชื่อที่หน่วยงานพิมพ์เพิ่มเองแล้วซ้ำกับไฟล์ ยึดข้อมูลจากไฟล์
- ตำแหน่ง: พยาบาลวิชาชีพ → RN, **หัวหน้าแผนก / ผู้ช่วยหัวหน้าแผนก / รักษาการหัวหน้าแผนก / ผู้จัดการ → RN**, ผู้ช่วยพยาบาล → PN, เจ้าหน้าที่ผู้ช่วยเหลือผู้ป่วย → NA, อื่นๆ → อื่นๆ (ตำแหน่งแปลงตอนอัปโหลด ถ้าอัปโหลดไว้ก่อนหน้านี้ให้อัปโหลดไฟล์ซ้ำเพื่อให้ใช้กฎใหม่)
- ในหน้าอัปโหลดมีปุ่มดาวน์โหลดไฟล์ตัวอย่าง (CSV)

## ไฟล์แนบของเหตุการณ์ผิดปกติ
- แนบได้ JPG / PNG / PDF สูงสุด 5 ไฟล์ต่อเหตุการณ์ รูปถูกย่อเหลือด้านยาวไม่เกิน 1600 พิกเซลอัตโนมัติ PDF ไม่เกิน 5 MB
- ไฟล์เก็บในโฟลเดอร์ `daily-report-attachments` ใน Google Drive ของเจ้าของระบบ (**ไม่เปิดสาธารณะ**) ดูได้ผ่านระบบนี้เท่านั้น (ต้องเข้าสู่ระบบ) กดชื่อไฟล์เพื่อเปิดดูและดาวน์โหลด
- ครั้งแรกที่ใช้ ระบบขอสิทธิ์ Google Drive จากเจ้าของระบบ: เปิดลิงก์ `/exec` ด้วยบัญชีเจ้าของแล้วกดอนุญาต (หรือเลือกฟังก์ชัน `authorizeDrive` แล้วกดเรียกใช้ใน Apps Script)
- หน้าพิมพ์ใส่ไฟล์แนบลงในรายงาน: รูปพิมพ์ตรงๆ PDF แสดงหน้าแรกๆ ได้สูงสุด 3 หน้า (ใช้ pdf.js จาก cdnjs)
- ไฟล์ที่ถูกเอาออกจากรายงานยังค้างในโฟลเดอร์ ลบเองใน Drive ได้

## วิธีติดตั้ง
1. สร้าง Google Sheets ใหม่ → **ส่วนขยาย → Apps Script**
2. สร้างไฟล์ให้ครบ: `Code.gs`, `Schema.gs` (สคริปต์) และ `Index` (HTML) แล้ววางโค้ดจาก repo
3. ⚙️ การตั้งค่าโปรเจกต์ → เขตเวลา **(GMT+07:00) Bangkok**
4. (ไม่บังคับ) เปิดไฟล์ `Code.gs` → เลือกฟังก์ชัน **`setup`** แล้วกด **เรียกใช้** — ถ้าข้ามขั้นนี้ ระบบจะสร้างชีตและรหัสผ่านให้เองเมื่อเปิดหน้าเว็บครั้งแรก
5. **ทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - ดำเนินการในฐานะ: **ฉัน**
   - ผู้มีสิทธิ์เข้าถึง: **ทุกคน** (ไม่ต้องมีบัญชี Google)
6. เปิด URL `/exec` หนึ่งครั้ง (ระบบสร้างชีต `ผู้ใช้` ให้) แล้วแจก URL กับรหัสผ่านจากชีตนั้นให้แต่ละหน่วยงาน

แก้โค้ดแล้วต้อง Deploy เวอร์ชันใหม่: จัดการการทำให้ใช้งานได้ → ✏️ แก้ไข → เวอร์ชันใหม่ (URL เดิม)
